PDM: PA2 + PA4 DATA1 Audio out: LINEOUT -> AXS2033 -> CN2 NAND: GD5F1GM7UEYIGR LCD: MIPI DSI D0/D1/CLK Touch: Sitronix candidate 0x55 BL702: UART1 + reset + boot

固件工程师入口地图

语音输入

PA2=PDM_CLK，PA4=PDM_DAT1，HAL DATA1 应绑定 DMIC3/DMIC4。先看 pinmux 日志，再测 PDM 波形。

E2-E5 A

音频输出

Audio HAL speaker/line-out 到 LINEOUT_LN/LP，进入 U7 AXS2033，BTL 到 CN2。小声优先测 U7 pin1。

E8-E12 A

LCD/Touch

CN6 引出 DSI 两 data lane、clock、reset、backlight 和 touch I2C。lane/timing 需要配置化。

E17-E20 B

NAND

U11 是 GD5F1GM7UEYIGR SPI NAND 128MB，烧录使用 NAND profile。

E14-E16 A/B

BL702

UART1 连接 BL702，GPIO28 boot strap：低=Flash，高=UART。默认不要拉高。

E21-E23 A/B

电源/复位

LCD/Zigbee 子电源由 GPIO 管理；CHIP_EN 不等于全板断电。初始化应主动 reset 外设。

E25 A

避坑指南 / 注意事项

主题容易错的点影响第一检查证据
DMIC DATA1误配成 DATA0/DMIC1/2有帧但无有效输入日志必须是 DMIC3/DMIC4E2-E5
AXS2033 SD把 SD 当普通 enable小声、失真、无声测 U7 pin1 电压E9/E11
CN2 BTL把一端当地测量错误或短路风险差分测 SPK_OUTP/NE12
软件音量当前已默认最大，还继续调上层音量浪费定位时间先测 SD/LINEOUT/AXS outputE6
LCD lane原理图两 lane，init table 疑似一 lane白屏/花屏lane_count 配置化并实测E17/E20
Touch 地址把 0x55 当定论probe 失败reset 后 scan + chip idE19
NAND profileNAND/NOR 混用烧录失败或布局错误固定 NAND profileE14-E16
