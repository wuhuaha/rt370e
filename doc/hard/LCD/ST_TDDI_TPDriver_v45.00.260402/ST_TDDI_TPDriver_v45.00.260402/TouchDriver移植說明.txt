2.整機測試時，請先確認 開機是否有類似以下訊息

	IC SFR VER = 0x43， 若為 0或0xFF，表示通訊有異常

	預設開啟 #define ST_UPGRADE_USE_REQUESTFW_BUF
	請將固件 dump (FW+CFG) 放置於 request_firmware 目錄下, 資料夾位置依平台有所差異。
	預設檔案名稱為7123.dump，若需修改，請修改ST_REQUESTFW_DF_PATH名稱。
	若沒出現sitronix_spi_hdl_fw success ，代表host download 過程有錯誤

	若FW revision (hex) = 1 17 1 15，不是這種格式，代表FW 內容有誤，需更新固件
	若以上資訊都有，但無觸控，表示FAE還需要再調適touch 效果(稱CFG)
	PS：初版driver 上的 FW、CFG 不一定適用客戶模組，可能要等調適完成後再替換固件

1、/sys/sitronix_ts_attrs/stmodeswitch

	若需其他串口，請自行建立並呼叫 sitronix_mode_switch

4.Self測試

	設定與函數都位於 sitronix_ts_test.c內
	執行後會建立測試檔案：

6.grip 旋轉手機
	函數位於 utility.c 的 int sitronix_mode_switch_value(int modeID, bool flag, unsigned char value);
	modeID 為7 時， 可用 flag 與 value 切換手機旋轉狀態，預設為關閉
	flag: true , 開啟功能
	flag: false ,關閉功能
	value 如下
	typedef enum {
		ST_MODE_GRIP_ROTATE_0		=	0,
		ST_MODE_GRIP_ROTATE_90		=	1,
		ST_MODE_GRIP_ROTATE_180		=	2,
		ST_MODE_GRIP_ROTATE_270		=	3,	
	} ST_MODE_GRIP_ROTATE_VALUE;

	目前已存在的對外串口：
	6.1、/sys/sitronix_ts_attrs/stmodeswitch
		echo 07 0 > /sys/sitronix_ts_attrs/stmodeswitch    開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_0
		echo 07 1 > /sys/sitronix_ts_attrs/stmodeswitch    開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_90
		echo 07 2 > /sys/sitronix_ts_attrs/stmodeswitch    開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_180
		echo 07 3 > /sys/sitronix_ts_attrs/stmodeswitch    開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_270
		echo 07 {not 0 1 2 3} > /sys/sitronix_ts_attrs/stmodeswitch    關閉grip功能

	6.2、/proc/sitronix/grip
		"echo 0 > /proc/sitronix/grip"		 開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_0
		"echo 90 > /proc/sitronix/grip"		 開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_90
		"echo 180 > /proc/sitronix/grip"	 開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_180
		"echo 270 > /proc/sitronix/grip"	 開啟grip功能，並設為 ST_MODE_GRIP_ROTATE_270
		"echo on > /proc/sitronix/grip"		 開啟grip功能，方向為上一次設定的方向
		"echo off > /proc/sitronix/grip"	 關閉grip功能
		可用程式對此proc寫 0/90/180/270/on/off
		若需其他串口，請自行建立並呼叫 sitronix_mode_switch_value

9. /proc/sitronix/stproximity
	
	(驅動 "Sitronix TDDI Touch Driver v43.00.240328" 可以支持 ST7121P proximity功能)
	
	開啟 #define SITRONIX_SUPPORT_PROXIMITY編譯即可。
	
	目前驅動有提供節點開關proximity功能。
	/proc/sitronix/stproximity

	使用方式如下：

	(1) 開啟 proximity功能：
	adb shell "echo 1 > /proc/sitronix/stproximity"

	(2)關閉 proximity功能：
	adb shell "echo 0 > /proc/sitronix/stproximity"

	(3)滅屏時啟用 proximity 功能。 proximity需要在sleep out 時才有動作。
	執行這個指令，驅動會在滅屏狀況(sitroinx_ts_suspend之後)下display driver 11 指令，讓display進入 sleep out，此時才會有proximity功能。

	adb shell "echo 2 > /proc/sitronix/stproximity"

	執行狀況如下：
	(1) 亮屏時開啟 proximity，會在kernel log打印狀態 0, 1, 2, 或3。 0表是未偵測，1到3表示與TP距離狀態，1表示偵測到有物體靠近，3表示已貼到屏上。
	(2) 滅屏時啟用 proximity，會在kernel log打印狀態4或5。4表示貼在屏上，5表示離開。

		static sitronix_sensor_key_t sitronix_sensor_key_array[] = {

			{KEY_HOME}, // bit 1
			{KEY_MENU}, // bit 2
		};

11. SWK Single/Double Tap 模式切換功能

	開啟 SWK Single Tap(單擊喚醒): echo 1 > /proc/sitronix/stswktapmode
	開啟 SWK Double Tap(雙擊喚醒): echo 2 > /proc/sitronix/stswktapmode

	(單擊與雙擊喚醒功能不能同時存在)


12. SWK 模式選擇功能

	開啟 SWK 預設手勢	: 
		echo 0 > /proc/sitronix/stswkselect
	開啟 SWK Signel Tap	: 
		echo 1 > /proc/sitronix/stswkselect
	開啟 SWK Double Tap	: 
		echo 2 > /proc/sitronix/stswkselect
	開啟 SWK Slide(滑動手勢，上、下、左、右):
		echo 3 > /proc/sitronix/stswkselect
	
	(選擇 1 ~ 3時，其他手勢無效。)

14. 下 Display Driver CMD 功能(for Debug Only)
	a. 可透過 /proc/sitronix/stdrivercmd 或 /sys/sitronix_ts_attrs/stdrivercmd 寫或讀 Display Driver CMD。
	b. 讀 Driver CMD：(回讀 0Ah 內容 2 個 bytes)
		echo "r a 2" > /proc/sitronix/stdrivercmd
	c. 寫 Driver CMD：(寫入 0Ah 內容 2 個 bytes)
		echo "w a 1 2" > /proc/sitronix/stdrivercmd			//寫入的 Data 個數要為 2 的倍數
	d. 注意：透過節點讀寫 Driver CMD 方式，部分 Driver CMD 只能寫入，無法讀出內容。
