SWK ON/OFF¡G
The function, int sitronix_mode_switch(int modeID, bool flag), is in sitronix_st7123_utility.c.

The 'modeID' of SWK is 1. 
Set the 'flag' as 'true' to enable SWK, 'false' to disable SWK.

The touch device creates both 'sysfs' and 'device node' to enable or disable SWK:
	(1) /sys/sitronix_ts_attrs/stmodeswitch
		"echo 01 00 > /sys/sitronix_ts_attrs/stmodeswitch"    //disable SWK
		"echo 01 01 > /sys/sitronix_ts_attrs/stmodeswitch"    //enable SWK

	(2) /proc/sitronix/swu
		"echo off > /proc/sitronix/swu"	//disable SWK
		"echo on > /proc/sitronix/swu"	//enable SWK
		

4.Self test

	After executing the Self test, normal / open / short / STD (RAW data stability) test will be performed.
	Settings and functions are located in sitronix_ts_test.c
	After execution, a test file will be created:
	#define ST_SELFTEST_LOG_PATH "/sdcard/ST_SELFTEST_LOG.txt"

	Currently existing external test entry points:
	
	[Method 1]
	/sys/sitronix_ts_attrs/stselftest
	"echo 1 > /sys/sitronix_ts_attrs/stselftest" starts the test
	"cat /sys/sitronix_ts_attrs/stselftest" check the test results

	[Method 2]
	/proc/sitronix/stselftest"
	"echo 1 > /proc/sitronix/stselftest"	starts the test
	"cat /proc/sitronix/stselftest"		check the test results

	int sitronix_selftest_result_read(void) Get test results, 1 ok, 0 fail

6. The GRIP function is used for handling the rotaion of the device.
The funcion, int sitronix_mode_switch_value(int modeID, bool flag, unsigned char value), is in sitronix_st7123_utility.c.
The 'modeID' of GRIP is 7. 
Set the 'flag' as 'true' to enable SWK, 'false' to disable SWK.
Set the 'value' for rotation, the degree is in clockwise.
typedef enum {
	ST_MODE_GRIP_ROTATE_0		=	0,
	ST_MODE_GRIP_ROTATE_90		=	1,
	ST_MODE_GRIP_ROTATE_180		=	2,
	ST_MODE_GRIP_ROTATE_270		=	3,	
} ST_MODE_GRIP_ROTATE_VALUE;

The deivce nodes for GRIP are:
	(1)/sys/sitronix_ts_attrs/stmodeswitch
		"echo 07 0 > /sys/sitronix_ts_attrs/stmodeswitch"			//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_0
		"echo 07 1 > /sys/sitronix_ts_attrs/stmodeswitch" 			//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_90
		"echo 07 2 > /sys/sitronix_ts_attrs/stmodeswitch"			//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_180
		"echo 07 3 > /sys/sitronix_ts_attrs/stmodeswitch"			//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_270
		"echo 07 {not 0 1 2 3} > /sys/sitronix_ts_attrs/stmodeswitch"	//Trun off GRIP

	(2)/proc/sitronix/grip
		"echo 0 > /proc/sitronix/grip"		//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_0
		"echo 90 > /proc/sitronix/grip"		//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_90
		"echo 180 > /proc/sitronix/grip"	//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_180
		"echo 270 > /proc/sitronix/grip"	//Turn on GRIP, set value as ST_MODE_GRIP_ROTATE_270
		"echo on > /proc/sitronix/grip"		//Turn on GRIP, keep the last rotation.
		"echo off > /proc/sitronix/grip"	//Trun off GRIP

9. /proc/sitronix/stproximity

	(The driver "Sitronix TDDI Touch Driver v43.00.240328" supports the ST7121P proximity function)

	Simply compile with #define SITRONIX_SUPPORT_PROXIMITY enabled.

	Currently, the driver provides a node toggle for proximity.
	/proc/sitronix/stproximity

	Usage is as follows:

	(1) Enable proximity function:
		adb shell "echo 1 > /proc/sitronix/stproximity"

	(2) Disable proximity function:
		adb shell "echo 0 > /proc/sitronix/stproximity"

	(3) Enable proximity function when the screen is off. Proximity only works when the screen is asleep. Executing this command will cause the driver to enter sleep mode (after `sitroinx_ts_suspend`) under the `display driver 11` command, enabling proximity functionality.
		adb shell "echo 2 > /proc/sitronix/stproximity"

	The execution status is as follows:
	(1) When the screen is on, proximity will be enabled, and the kernel log will print status 0, 1, 2, or 3. 0 indicates no detection, 1 to 3 indicate the distance to the TP (Touch Panel), 1 indicates an object is detected approaching, and 3 indicates the object is on the screen.
	(2) When the screen is off, proximity will be enabled, and the kernel log will print status 4 or 5. 4 indicates the object is on the screen, and 5 indicates the object is away.

11. SWK Single/Double Tap Mode Switching

	Enable SWK Single Tap (single-click wake-up): echo 1 > /proc/sitronix/stswktapmode
	Enable SWK Double Tap (double-click wake-up): echo 2 > /proc/sitronix/stswktapmode

	(Single-click and double-click wake-up functions cannot coexist)


12. SWK Mode Selection

	Enable SWK Preset Gestures:
		echo 0 > /proc/sitronix/stswkselect
	Enable SWK Signel Tap:
		echo 1 > /proc/sitronix/stswkselect
	Enable SWK Double Tap:
		echo 2 > /proc/sitronix/stswkselect
	Enable SWK Slide (swipe gestures: up, down, left, right):
		echo 3 > /proc/sitronix/stswkselect

	(When selecting 1~3, other gestures are invalid.)

14. Accessing Display Driver CMD (for Debug Only)

	a. Display Driver CMD can be written to or read from via `/proc/sitronix/stdrivercmd` or `/sys/sitronix_ts_attrs/stdrivercmd`.
	b. Read Driver CMD: (Read back 2 bytes of content from 0Ah)
		echo "r a 2" > /proc/sitronix/stdrivercmd
	c. Write Driver CMD: (Write 2 bytes of content from 0Ah)
		echo "w a 1 2" > /proc/sitronix/stdrivercmd //The number of bytes written must be a multiple of 2
	d. Note: When reading and writing Driver CMD via nodes, some Driver CMDs can only be written to, not read from.
